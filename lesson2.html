피코의 두뇌인 RP2350 칩 안에는 아주 작은 온도 감지 회로가 들어 있습니다. 원래는 칩이 너무 뜨거워지지 않았는지 스스로 확인하려고 넣어둔 것인데, 우리도 그 값을 읽어올 수 있어요.

ADC — 아날로그를 숫자로

지난 시간에 디지털 신호는 0과 1 두 가지뿐이라고 했습니다. 그런데 온도는 27도와 28도 사이에 27.3도가 있고, 그 사이에도 무한히 많은 값이 있죠. 이렇게 연속적으로 변하는 양이 아날로그입니다.

컴퓨터는 숫자만 다룰 수 있으니, 아날로그를 숫자로 바꿔주는 장치가 필요합니다. 그게 ADC(Analog-Digital Converter, 아날로그-디지털 변환기)예요. 피코 안에 들어 있고, 앞으로 우리가 쓸 가스 센서·토양 수분 센서·조도 센서가 전부 이 ADC를 거쳐 갑니다.

센서는 온도를 재지 않습니다

이상하게 들리겠지만 사실입니다. 센서가 실제로 재는 것은 전압이에요. 온도가 오르면 전압이 내려가는 부품이 들어 있을 뿐이죠.

"이 전압은 몇 도에 해당한다"고 계산해서 붙여주는 건 우리입니다. 오늘 그 계산을 직접 해봅니다.

활동 1. 숫자 하나 읽기

목표 — ADC가 주는 날것의 값을 확인한다

편집 영역에 아래 세 줄을 적고 실행해 보세요. 저장은 temp.py라는 이름으로 Raspberry Pi Pico에 합니다.

from machine import ADC

sensor = ADC(4)          # 4번 = 내부 온도 센서
print(sensor.read_u16())

알 수 없는 다섯 자리 숫자가 나왔을 겁니다. 14000 근처겠네요.

이 숫자는 온도가 아닙니다. ADC가 전압을 0부터 65535까지의 눈금으로 표현한 값이에요. 0은 0V, 65535는 3.3V를 뜻합니다. read_u16의 16은 이 눈금이 16비트라는 뜻이고요.

여러 번 실행해 보세요. 매번 조금씩 다른 숫자가 나옵니다. 이건 나중에 다시 이야기합니다.

왜 하필 4번일까

피코의 ADC는 여러 개의 입구를 가지고 있습니다. 0·1·2번은 우리가 밖에서 센서를 꽂을 자리(A0·A1·A2)이고, 4번은 칩 내부의 온도 센서에 미리 연결되어 있습니다. 그래서 아무것도 안 꽂아도 읽을 수 있는 거예요.

숫자를 온도로 바꾸기

3.2 · 두 번의 계산

첫 번째 — 숫자를 전압으로

65535가 3.3V니까, 우리가 받은 숫자가 몇 V인지는 비례로 구합니다.

전압 = 숫자 × 3.3 ÷ 65535

14000이면 약 0.705V가 나옵니다.

두 번째 — 전압을 온도로

피코 설명서에는 이 센서에 대해 딱 두 가지가 적혀 있습니다.

  • 27도일 때 0.706V가 나온다
  • 온도가 1도 오를 때마다 0.001721V씩 낮아진다

이 두 개만 알면 온도를 거꾸로 계산할 수 있습니다.

온도 = 27 − (전압 − 0.706) ÷ 0.001721

맨 위 계산기에서 숫자가 커질수록 온도가 내려간 이유가 이겁니다. 온도가 오르면 전압이 내려가는 부품이거든요. 그래서 식에 뺄셈이 들어 있습니다.

코드로 옮기기

from machine import ADC
import time

sensor = ADC(4)

while True:
    raw = sensor.read_u16()
    volt = raw * 3.3 / 65535
    temp = 27 - (volt - 0.706) / 0.001721

    print(raw, round(volt, 3), round(temp, 1))
    time.sleep(1)

1초에 한 줄씩, 세 개의 값이 나란히 찍힙니다. 왼쪽부터 날것의 숫자, 전압, 온도예요. 세 숫자가 어떻게 연결되는지 눈으로 확인해 보세요.

round는 반올림입니다

round(temp, 1)은 소수점 아래 한 자리까지만 남기라는 뜻이에요. 안 쓰면 27.35819403159 같은 숫자가 나와서 읽기 힘듭니다.

활동 2. 온도를 바꿔보기

목표 — 센서가 무엇에 반응하는지 직접 확인한다

코드를 계속 돌려둔 채로 아래를 해보고, 값이 얼마나 그리고 얼마나 빨리 변하는지 관찰하세요.

1
손으로 감싸기

피코를 손바닥으로 30초쯤 감싸 보세요. 몇 도까지 올라가나요? 손을 떼면 원래대로 돌아오는 데 얼마나 걸리나요?

2
입김 불기

후 하고 불어 보세요. 손보다 빠를까요, 느릴까요? 입김은 따뜻한데 값이 내려가는 경우도 있습니다. 왜 그럴지 생각해 보세요.

3
추운 곳에 두기

창가나 냉장고 근처에 놓아 보세요. 노트북에서 케이블이 닿는 만큼만요. 몇 분 뒤 값이 어떻게 되나요?

관찰의 핵심은 '속도'입니다

센서마다 반응 속도가 다릅니다. 즉시 변하는 센서도 있고, 몇 분이 걸리는 센서도 있어요. 앞으로 받을 가스 센서는 아주 느립니다. 지금 이 감각을 익혀두면 그때 당황하지 않습니다.

활동 3. 값이 자꾸 흔들린다

목표 — 측정값 하나를 믿으면 안 되는 이유를 안다

피코를 가만히 둬도 값이 계속 바뀝니다. 27.3, 26.8, 27.6, 27.1... 방 온도가 1초 만에 변한 게 아닌데도 그렇습니다.

이걸 노이즈라고 부릅니다. 전기 신호에는 아주 작은 떨림이 항상 섞여 있어요. 완전히 없앨 수는 없습니다.

버튼을 눌러보세요.

해결책 — 여러 번 재서 평균 내기

한 번 잰 값은 못 믿어도, 열 번 재서 평균을 내면 훨씬 안정됩니다. 위 버튼을 여러 번 눌러 보세요. 개별 값은 매번 다르지만 평균은 비슷하게 나옵니다.

from machine import ADC
import time

sensor = ADC(4)

def read_temp():
    volt = sensor.read_u16() * 3.3 / 65535
    return 27 - (volt - 0.706) / 0.001721

while True:
    values = []
    for i in range(10):        # 10번 재서
        values.append(read_temp())
        time.sleep(0.05)

    avg = sum(values) / len(values)   # 평균 내기
    print(round(avg, 1))
    time.sleep(1)

sum은 다 더하기, len은 개수 세기입니다. 더한 값을 개수로 나누면 평균이죠.

실행해서 아까 코드와 비교해 보세요. 숫자가 훨씬 얌전해졌을 겁니다.

몇 번이 적당할까?

많이 잴수록 안정되지만 그만큼 느려집니다. 100번 재면 값 하나 얻는 데 5초가 걸리죠. 10을 20으로, 5로 바꿔가며 어디가 적당한지 직접 정해 보세요. 정답은 없고 상황에 따라 다릅니다.

활동 4. 진짜 온도와 비교하기

목표 — 센서가 재는 것과 내가 알고 싶은 것을 구분한다

집에 있는 온도계나 스마트폰 날씨 앱으로 방 온도를 확인하고, 피코 값과 비교해 보세요.

아마 피코 쪽이 몇 도 높게 나올 겁니다. 방이 22도인데 피코는 27도라고 하는 식으로요.

고장이 아닙니다. 이 센서는 칩 자체의 온도를 재고 있거든요. 칩은 일을 하면서 스스로 열을 냅니다. 사람으로 치면 체온을 재놓고 "오늘 날씨가 36.5도네"라고 말하는 셈이에요.

오늘 가장 중요한 문장

센서가 재는 것과 우리가 알고 싶은 것은 다를 수 있습니다.

앞으로 받을 센서들도 마찬가지예요. 가스 센서는 "담배 연기"를 재는 게 아니라 공기 중 특정 성분에 반응할 뿐이고, 토양 수분 센서는 "물"이 아니라 흙이 전기를 얼마나 잘 통하는지를 잽니다. 이 차이를 아는 것이 센서를 제대로 쓰는 첫걸음입니다.

그럼 이 센서는 쓸모가 없나요?

그렇지 않습니다. 절대적인 온도는 못 믿어도 변화는 잘 잡아냅니다. "지금 몇 도인가"에는 약하지만 "아까보다 따뜻해졌나"에는 강해요.

차이가 일정하다면 보정도 가능합니다. 방이 22도인데 피코가 27도라면, 코드에서 5를 빼주면 되겠죠. 다만 그 5가 항상 5일지는 확인해 봐야 합니다.

"아직 모르겠는 것"을 꼭 적어 주세요. 빈칸으로 두지 말고요. 모르는 걸 적는 건 실력이 없다는 뜻이 아니라, 자기가 어디까지 알고 있는지 정확히 안다는 뜻입니다.

점검하기

read_u16()이 돌려주는 숫자는 무엇인가요?
온도가 아니라, 전압을 0부터 65535까지의 눈금으로 나타낸 값입니다. 0이 0V, 65535가 3.3V예요.
숫자가 커지면 왜 온도가 내려가나요?
이 센서는 온도가 오르면 전압이 낮아지는 성질을 가지고 있습니다. 그래서 계산식에 뺄셈이 들어가고, 큰 숫자(=높은 전압)는 낮은 온도를 뜻하게 됩니다.
같은 자리에 가만히 뒀는데 값이 계속 바뀌는 이유는?
전기 신호에 항상 섞여 있는 작은 떨림(노이즈) 때문입니다. 없앨 수는 없고, 여러 번 재서 평균을 내면 영향을 줄일 수 있습니다.
피코 온도가 집 온도계보다 높게 나오는 이유는?
이 센서는 방 공기가 아니라 칩 자신의 온도를 잽니다. 칩이 동작하면서 스스로 열을 내기 때문에 주변 공기보다 따뜻합니다.
ADC는 무엇을 하는 장치인가요?
연속적으로 변하는 아날로그 신호(전압)를 컴퓨터가 다룰 수 있는 숫자로 바꿔주는 장치입니다. 앞으로 쓸 가스·토양·조도 센서가 모두 이걸 거쳐 갑니다.
