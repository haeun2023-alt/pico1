활동 1. 연결하기

목표 — 전원을 넣기 전에 선 네 가닥을 정확히 맞춘다
한눈에 보기 · 포트 I2C1 · 전원 스위치 5V · 노랑–파랑 · 흰색–초록 · 빨강–빨강 · 검정–검정
1
전원 스위치를 5V로

그로브 쉴드의 작은 스위치를 5V 쪽으로 밉니다. 허스키렌즈는 전기를 꽤 먹어서 5V가 안정적입니다.

2
I2C1 포트에 꽂기

그로브 케이블을 쉴드의 I2C1 포트에 꽂습니다. 바로 옆 I2C0이 아닙니다. 쉴드에 인쇄된 글자를 꼭 확인하세요.

3
허스키렌즈 케이블 꽂기

허스키렌즈 케이블의 흰 커넥터를 허스키렌즈의 4핀 단자(T R − +)에 꽂습니다. 위 그림에서 카메라 쪽 왼쪽 아래에 있는 흰 단자예요.

4
색을 맞춰 잇기

그로브 쪽 선과 허스키렌즈 쪽 선을 아래처럼 잇습니다. 색이 서로 다른 짝이 있으니 주의하세요.

그로브 쉴드 쪽허스키렌즈 쪽 노랑 SCL─파랑 R 흰색 SDA─초록 T 빨강 전원 +─빨강 + 검정 GND −─검정 −
5
전원 넣기 전 확인

빨강끼리, 검정끼리 이어졌는지 한 번 더 보세요. 이 둘이 바뀌면 허스키렌즈가 고장 날 수 있습니다. 확인했으면 사진을 찍어 두세요. 잘 모르겠으면 사진을 채팅에 올리고 확인받은 뒤 전원을 넣습니다.

6
USB 연결

USB 케이블은 피코에 꽂고 노트북에 연결합니다. 허스키렌즈의 USB 단자에는 꽂지 않아요. 몇 초 뒤 허스키렌즈 화면도 함께 켜지고, 카메라가 보는 장면이 나오면 성공입니다.

왜 색이 다른 선끼리 이을까

이름은 달라도 하는 일이 같은 선끼리 잇는 겁니다. 그로브의 노랑(SCL)은 박자를 맞추는 선, 흰색(SDA)은 데이터가 오가는 선입니다. 허스키렌즈에서는 같은 일을 파랑(R)과 초록(T)이 맡고 있어요.

5차시에 그로브 케이블은 선이 한 묶음이라 꽂기만 하면 된다고 했죠. 그리고 그로브가 아닌 부품을 쓰게 되면 직접 맞춰야 한다고도 했습니다. 오늘이 바로 그날이에요.

활동 2. 코드 없이 얼굴 학습하기

목표 — 허스키렌즈 혼자서 무엇을 할 수 있는지 본다

허스키렌즈는 피코 없이도 혼자 알아봅니다. 코딩 전에 먼저 손에 익혀 두세요.

1
Face Recognition 고르기

기능 버튼을 좌우로 돌려 화면 위쪽에 Face Recognition이 나오게 합니다.

2
얼굴 비추기

카메라를 얼굴 쪽으로 향하게 하고 30cm~1m쯤 떨어지세요. 얼굴에 흰 상자와 Face라는 글자가 생깁니다. 찾기는 했지만 누구인지는 모르는 상태예요.

3
학습시키기

화면 가운데 + 표시를 얼굴에 맞추고 학습 버튼을 짧게 누릅니다. 상자가 파란색으로 바뀌고 Face: ID1이 뜨면 성공입니다.

학습 버튼을 길게 누른 채 고개를 조금씩 돌리면 여러 각도를 기억해서 더 잘 알아봅니다.

4
잊게 하기

학습 버튼을 짧게 누르면 Click again to forget 같은 안내가 뜹니다. 숫자가 줄어드는 동안 한 번 더 누르면 기억이 지워집니다. 가만히 있으면 그대로 유지돼요.

맨 위 화면 흉내와 비교해 보세요

흰 상자는 "얼굴은 있는데 누군지 모름", 파란 상자에 ID가 붙으면 "학습한 사람"입니다. 피코는 이 차이를 ID 숫자로 받습니다. 모르는 얼굴은 0, 학습한 얼굴은 1부터예요.

얼굴은 개인정보입니다

가족 얼굴을 학습시키고 싶으면 먼저 허락을 받으세요. 그리고 실습이 끝나면 잊게 해 두는 습관을 들이세요. 이 이야기는 12월 성찰 글쓰기에서 다시 다룹니다.

활동 3. 통신 방식을 I2C로 바꾸기

목표 — 피코와 같은 말을 쓰도록 맞춘다 · 한 번만 하면 저장됨

허스키렌즈는 여러 방식으로 대화할 수 있습니다. 우리는 I2C로 쓰니 그렇게 맞춰 둡니다.

1
General Settings로 이동

기능 버튼을 돌려 화면 위쪽 이름이 General Settings가 되게 하고, 기능 버튼을 짧게 누릅니다.

2
Protocol Type → I2C

기능 버튼을 돌려 Protocol Type을 고르고 누릅니다. 다시 돌려 I2C를 고르고 누릅니다.

3
저장하고 나오기

기능 버튼을 돌려 Save & Return으로 가서 누릅니다. 저장할지 묻는 화면이 나오면 Yes를 고르고 누르세요.

저장을 꼭 하세요

Save & Return을 거치지 않고 빠져나오면 설정이 사라집니다. 다음 활동에서 연결이 안 되면 열에 아홉은 이 단계 때문이에요.

활동 4. 라이브러리 저장하고 연결 확인

목표 — 피코가 허스키렌즈를 찾는다

라이브러리 파일 저장

허스키렌즈와 대화하려면 정해진 신호 규칙을 따라야 합니다. 그 규칙을 미리 묶어 둔 파일이 라이브러리예요. 우리는 함수 이름만 부르면 됩니다. 3차시에 from wifi_config import ...로 다른 파일을 불러왔던 것과 같은 방식입니다.

1
파일 열기

선생님이 올려 둔 huskylensPythonLibrary.py를 받아 토니에서 엽니다. 파일을 못 받았으면 아래 상자를 펼쳐 복사해도 됩니다.

2
피코에 같은 이름으로 저장

파일 → 다른 이름으로 저장 → Raspberry Pi Pico → huskylensPythonLibrary.py. 대소문자까지 정확히 맞춰야 합니다. 내용은 고치지 마세요.

huskylensPythonLibrary.py 펼쳐 보기 (약 200줄) 
# ════════════════════════════════════════════════════════════
#  HuskyLens Python Library for Raspberry Pi Pico 2 W
#  (허스키렌즈 1세대 전용)
#
#  ★ 이 파일은 고치지 말고 그대로 피코에 저장하세요.
#    파일 이름 : huskylensPythonLibrary.py  (대소문자 정확히)
#
#  📌 연결 (I2C 모드)
#    - 그로브 쉴드의 [I2C1] 포트에 연결
#    - 그로브 쉴드 전원 스위치를 [5V]로
#    - 허스키렌즈 설정에서 Protocol Type 을 [I2C]로 바꾸고 저장
#
#  📌 핀
#    - I2C1 : SDA = GP6, SCL = GP7
#    - 통신 속도 50kHz (안정적으로 통신하기 위해 느리게)
#
#  📌 command_request_blocks() 가 돌려주는 값
#    [[x, y, w, h, ID], [x, y, w, h, ID], ...]
#    x, y : 상자 가운데 위치 (화면 크기 320 x 240)
#    w, h : 상자의 너비와 높이
#    ID   : 학습한 번호 (학습 안 된 것은 0)
#    아무것도 없으면 빈 리스트 []
#
#  2026.10 수정 : 좌표 값이 255를 넘으면 잘못 계산되던 문제 수정
#  Library credits: RRoy https://community.dfrobot.com/makelog-310469.html

COMMAND_REQUEST_CUSTOMNAMES = 0x2f
COMMAND_REQUEST_TAKE_PHOTO_TO_SD_CARD = 0x30
COMMAND_REQUEST_SAVE_MODEL_TO_SD_CARD = 0x32
COMMAND_REQUEST_LOAD_MODEL_FROM_SD_CARD = 0x33
COMMAND_REQUEST_CUSTOM_TEXT = 0x34
COMMAND_REQUEST_CLEAR_TEXT = 0x35

COMMAND_REQUEST_FORGET = 0x37
COMMAND_REQUEST_SCREENSHOT_TO_SD_CARD = 0x39
COMMAND_REQUEST_FIRMWARE_VERSION = 0x3C


class HuskyLensLibrary:
    def __init__(self, proto):
        self.proto = proto
        self.address = 0x32
        if self.proto == "SERIAL":
            # UART 모드: Pico UART0
            # 파랑(허스키 TX) → GP1, 녹색(허스키 RX) → GP0
            self.huskylensSer = UART(0, baudrate=9600, tx=Pin(0), rx=Pin(1), timeout=1000)
            time.sleep(0.1)
            while self.huskylensSer.any():
                self.huskylensSer.read()
        else:
            # I2C 모드: 그로브 쉴드 I2C1 포트 (SDA=GP6, SCL=GP7), 50kHz
            self.huskylensSer = I2C(1, scl=Pin(7), sda=Pin(6), freq=50000)
        self.lastCmdSent = ""

    def writeToHuskyLens(self, cmd):
        self.lastCmdSent = cmd
        if self.proto == "SERIAL":
            self.huskylensSer.write(cmd)
        else:
            self.huskylensSer.writeto(self.address, cmd)

    def calculateChecksum(self, hexStr):
        total = 0
        for i in range(0, len(hexStr), 2):
            total += int(hexStr[i:i + 2], 16)
        hexStr = hex(total)[-2:]
        return hexStr

    def cmdToBytes(self, cmd):
        return ubinascii.unhexlify(cmd)

    def splitCommandToParts(self, str):
        headers = str[0:4]
        address = str[4:6]
        data_length = int(str[6:8], 16)
        command = str[8:10]
        if data_length > 0:
            data = str[10:10 + data_length * 2]
        else:
            data = []
        checkSum = str[2 * (6 + data_length - 1):2 * (6 + data_length - 1) + 2]
        return [headers, address, data_length, command, data, checkSum]

    def getBlockOrArrowCommand(self):
        if self.proto == "SERIAL":
            byteString = self.huskylensSer.read(5)
            byteString += self.huskylensSer.read(int(byteString[3]))
            byteString += self.huskylensSer.read(1)
        else:
            byteString = self.huskylensSer.readfrom(self.address, 5)
            byteString += self.huskylensSer.readfrom(self.address, byteString[3] + 1)
        commandSplit = self.splitCommandToParts(''.join(['%02x' % b for b in byteString]))
        return commandSplit[4]

    def processReturnData(self):
        try:
            if self.proto == "SERIAL":
                byteString = self.huskylensSer.read(5)
                if byteString is None or len(byteString) < 5:
                    print("Read error (응답 없음 - 배선/모드 확인 필요)")
                    return []
                byteString += self.huskylensSer.read(int(byteString[3]))
                byteString += self.huskylensSer.read(1)
            else:
                byteString = self.huskylensSer.readfrom(self.address, 5)
                byteString += self.huskylensSer.readfrom(self.address, byteString[3] + 1)
            commandSplit = self.splitCommandToParts(''.join(['%02x' % b for b in byteString]))
            if commandSplit[3] == "2e":
                return "Knock Recieved"
            else:
                returnData = []
                numberOfBlocksOrArrow = int(
                    commandSplit[4][2:4] + commandSplit[4][0:2], 16)
                numberOfIDLearned = int(
                    commandSplit[4][6:8] + commandSplit[4][4:6], 16)
                frameNumber = int(
                    commandSplit[4][10:12] + commandSplit[4][8:10], 16)
                for i in range(numberOfBlocksOrArrow):
                    returnData.append(self.getBlockOrArrowCommand())
                finalData = []
                tmp = []
                for i in returnData:
                    tmp = []
                    for q in range(0, len(i), 4):
                        # 2바이트 값 = 아래 바이트 + 위 바이트 x 256
                        # (2026.10 수정: 예전에는 x 256 이 빠져 있어
                        #  x 좌표가 255를 넘으면 엉뚱한 값이 나왔음)
                        low = int(i[q:q + 2], 16)
                        high = int(i[q + 2:q + 4], 16)
                        tmp.append(low + high * 256)
                    finalData.append(tmp)
                    tmp = []
                return finalData
        except Exception as e:
            print("Read error:", e)
            return []

    def command_request_knock(self):
        cmd = self.cmdToBytes(commandHeaderAndAddress + "002c3c")
        self.writeToHuskyLens(cmd)
        return self.processReturnData()

    def command_request_blocks(self):
        cmd = self.cmdToBytes(commandHeaderAndAddress + "002131")
        self.writeToHuskyLens(cmd)
        return self.processReturnData()

    def command_request_arrows(self):
        cmd = self.cmdToBytes(commandHeaderAndAddress + "002232")
        self.writeToHuskyLens(cmd)
        return self.processReturnData()

    def color_recognition_mode(self):
        cmd = self.cmdToBytes(commandHeaderAndAddress + "022d040043")
        self.writeToHuskyLens(cmd)
        return self.processReturnData()

    def face_recognition_mode(self):
        cmd = self.cmdToBytes(commandHeaderAndAddress + "022d00003f")
        self.writeToHuskyLens(cmd)
        return self.processReturnData()

    def object_tracking_mode(self):
        cmd = self.cmdToBytes(commandHeaderAndAddress + "022d010040")
        self.writeToHuskyLens(cmd)
        return self.processReturnData()

    def object_recognition_mode(self):
        cmd = self.cmdToBytes(commandHeaderAndAddress + "022d020041")
        self.writeToHuskyLens(cmd)

    def tag_recognition_mode(self):
        cmd = self.cmdToBytes(commandHeaderAndAddress + "022d050044")
        self.writeToHuskyLens(cmd)
        return self.processReturnData()

    def command_request_algorthim(self, alg):
        if alg in algorthimsByteID:
            cmd = commandHeaderAndAddress + "022d" + algorthimsByteID[alg]
            cmd += self.calculateChecksum(cmd)
            cmd = self.cmdToBytes(cmd)
            self.writeToHuskyLens(cmd)
            return self.processReturnData()
        else:
            print("INCORRECT ALGORITHIM NAME")

    def command_request_learn_once(self, id):
        cmd = commandHeaderAndAddress
        dataLength = 2
        cmd += "{:02x}".format(dataLength)
        cmd += "{:02x}".format(COMMAND_REQUEST_LEARN_ONECE)
        id = [id & 0xff, (id >> 8) & 0xff]
        cmd += "{:02x}".format(id[0])
        cmd += "{:02x}".format(id[1])
        cmd += self.calculateChecksum(cmd)
        cmd = self.cmdToBytes(cmd)
        self.writeToHuskyLens(cmd)
        return self.processReturnData()

    def command_request_forget(self):
        cmd = commandHeaderAndAddress
        dataLength = 0
        cmd += "{:02x}".format(dataLength)
        cmd += "{:02x}".format(COMMAND_REQUEST_FORGET)
        cmd += self.calculateChecksum(cmd)
        cmd = self.cmdToBytes(cmd)
        self.writeToHuskyLens(cmd)
        return self.processReturnData()

MQ2는 0~65535 사이 숫자 하나를 보냈고, 그 숫자가 무슨 뜻인지는 우리가 정했습니다. 허스키렌즈는 이미 판단한 결과를 보냅니다. "여기에 얼굴, 1번 사람." 그 판단이 틀릴 수도 있다는 점은 활동 7에서 확인합니다.

활동 6. 스마트 도어락 만들기

목표 — 판단 결과로 LED를 움직인다

등록된 얼굴이면 초록, 모르는 얼굴이면 빨강을 켭니다. LED 스틱을 D16에 꽂으세요. 허스키렌즈는 I2C1에 그대로 둡니다.

from huskylensPythonLibrary import HuskyLensLibrary
from machine import Pin
from neopixel import NeoPixel
import time

TIMING = (280, 515, 515, 745)    # WS2813 전용 타이밍
LED_COUNT = 10                   # ★ 스틱 10, 스트립 60

led = NeoPixel(Pin(16), LED_COUNT, timing=TIMING)
board_led = Pin("LED", Pin.OUT)  # 피코 내장 LED


def fill(color):
    """LED 전체를 한 가지 색으로"""
    for i in range(LED_COUNT):
        led[i] = color
    led.write()


husky = HuskyLensLibrary("I2C")
time.sleep(0.5)
husky.face_recognition_mode()
time.sleep(0.5)
print("스마트 도어락 시작! 카메라를 봐 주세요.")

while True:
    result = husky.command_request_blocks()

    if result:
        x, y, w, h, face_id = result[0]      # 첫 번째 얼굴만 본다
        if face_id > 0:
            print("문 열림 - ID", face_id, "님 확인")
            fill((0, 60, 0))                 # 초록
            board_led.on()
        else:
            print("등록되지 않은 얼굴입니다")
            fill((60, 0, 0))                 # 빨강
            board_led.off()
    else:
        print("얼굴 없음")
        fill((0, 0, 0))
        board_led.off()

    time.sleep(0.2)

코드 읽기

  • if result: — 리스트가 비어 있지 않으면, 즉 얼굴이 하나라도 보이면
  • x, y, w, h, face_id = result[0] — 첫 번째 상자의 다섯 숫자를 다섯 이름에 나눠 담기
  • if face_id > 0: — ID가 1 이상, 즉 학습한 얼굴이면

더 해 보기

  • 문이 열리면 3초 동안 초록을 유지했다가 꺼지게 하기
  • 모르는 얼굴이 계속 보이면 빨강으로 깜빡이며 경고하기
  • ID 1은 초록, ID 2는 파랑처럼 사람마다 다른 색 (여러 얼굴 학습은 다음 시간에 배웁니다)

AI에게 부탁해도 좋습니다. 단 LED 이야기를 할 때는 6차시에 배운 TIMING 문장을 꼭 붙이세요.

점검하기

허스키렌즈는 피코에게 사진을 보내나요?
보내지 않습니다. 허스키렌즈 안의 AI 칩이 스스로 판단하고, 그 결과(위치·크기·번호)만 숫자로 보냅니다.
[[250, 100, 60, 70, 0]]은 무슨 뜻인가요?
화면 오른쪽쯤(x=250)에 얼굴이 하나 있고, 학습하지 않은 사람(ID 0)이라는 뜻입니다.
허스키렌즈를 연결할 때 꼭 맞춰야 하는 세 가지는?
쉴드의 I2C1 포트, 전원 스위치 5V, 허스키렌즈 설정의 Protocol Type을 I2C로 바꾸고 저장하기입니다.
i2c.scan()에서 나온 50은 무엇인가요?
허스키렌즈의 I2C 주소입니다. 같은 선에 여러 장치가 연결되어도 주소로 서로 구분합니다.
허스키렌즈 도어락을 실제 현관에 쓰면 안 되는 이유는?
얼굴 모양만 비교하고 살아 있는 사람인지 확인하지 않아서 사진으로 속을 수 있고, 조명이나 각도에 따라 알아보지 못할 때도 있기 때문입니다.
