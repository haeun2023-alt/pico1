지난 시간 복습

0. 돌아보기 — 2차시 자료

지난 시간에 피코 속 온도 센서로 아날로그 값을 숫자로 읽는 법을 배웠습니다. 기억할 것 세 가지만 다시 짚습니다.

  • ADC(4).read_u16()은 온도가 아니라 0~65535 눈금의 숫자를 준다
  • 측정값은 항상 흔들린다. 여러 번 재서 평균을 낸다
  • 센서가 재는 것과 내가 알고 싶은 것은 다를 수 있다

오늘 재는 와이파이 신호도 똑같습니다. 숫자 하나는 못 믿고, 재는 값이 곧 "인터넷 속도"는 아닙니다.

시작 전 확인

USB를 꽂고 오른쪽 아래가 MicroPython (Raspberry Pi Pico)인지, 셸에 >>>가 보이는지 확인하세요. 실습용 와이파이 이름과 비밀번호는 선생님이 칠판에 알려줍니다. 이 페이지에는 적혀 있지 않아요. 왜 안 적었는지는 활동 1에서 이야기합니다.

와이파이는 어떻게 재나

1. 돌아보기

와이파이는 전파입니다. 공유기가 전파를 쏘고, 우리 폰이나 피코가 그걸 받아요. 거리가 멀어지거나 벽을 지나면 전파가 약해집니다.

받는 쪽에서 "지금 얼마나 세게 들어오나"를 잰 값이 RSSI(Received Signal Strength Indicator, 수신 신호 세기)입니다. 단위는 dBm이고요.

RSSI느낌보통 어디서
-30 ~ -50아주 좋음공유기(AP) 바로 옆
-50 ~ -67좋음같은 교실
-67 ~ -75보통벽 하나 건너, 복도
-75 ~ -85약함다른 층, 먼 교실
-85 이하거의 안 됨계단실, 운동장
왜 마이너스일까

dBm은 1mW(밀리와트)를 기준 0으로 잡은 단위입니다. 와이파이 전파는 공기 중에서 엄청나게 약해져서, 받을 때는 1mW보다 훨씬 작아요. 그래서 전부 마이너스로 나옵니다. -40이 -80보다 강합니다. 처음엔 헷갈리니 "0에 가까울수록 좋다"로 외우세요.

피코는 2.4GHz만 됩니다

요즘 공유기는 와이파이를 두 개 쏩니다. 학교 것도 마찬가지예요. 이름 끝에 5G가 붙은 것과 안 붙은 것. 피코는 5G가 붙지 않은 쪽(2.4GHz)에만 연결됩니다. 오늘 연결이 안 되면 열에 아홉은 이것 때문이에요.

활동 1. 비밀은 따로 두기

목표 — 비밀번호를 코드와 분리해서 저장한다

와이파이 비밀번호를 코드 안에 직접 적으면, 나중에 코드를 친구에게 보여주거나 깃허브에 올릴 때 비밀번호가 같이 올라갑니다. 그래서 비밀은 별도 파일에 둡니다.

새 파일을 만들고 아래처럼 적은 뒤, Raspberry Pi Pico에 wifi_config.py라는 이름으로 저장하세요. 이름이 정확해야 합니다.

이 세 줄은 복사하지 말고 직접 치세요. 짧기도 하고, 내 비밀번호를 내 손으로 넣어보는 게 오늘의 핵심이니까요.

# 실습용 와이파이 정보 - 이 파일은 공유하지 않는다
WIFI_SSID = "선생님이알려준이름"
WIFI_PASSWORD = "비밀번호"

따옴표 안을 칠판에 적힌 이름과 비밀번호로 바꿉니다. 대소문자와 띄어쓰기까지 정확히 써야 해요. 집에서 할 때는 집 와이파이 정보로 바꾸면 됩니다.

이 페이지에 비밀번호가 없는 이유

이 페이지는 인터넷에 공개되어 있어서, 여기에 학교 와이파이 비밀번호를 적으면 전 세계 누구나 볼 수 있습니다. 그래서 칠판에만 적고 지우는 거예요. 여러분 코드도 마찬가지입니다.

몇 주 뒤 AI API를 쓸 때 API 키라는 걸 받게 됩니다. 그게 새어나가면 남이 내 돈으로 AI를 쓸 수 있어요. 오늘 배우는 "비밀은 별도 파일에, 파일은 공유하지 않기"가 그때 그대로 쓰입니다. 깃허브에 올릴 때 이 파일은 빼는 것도 잊지 마세요.

활동 2. 연결하고 신호 재기

목표 — 피코를 와이파이에 붙이고 RSSI를 읽는다

이번엔 코드가 기니까 직접 치지 마세요. 아래 코드의 [복사] 버튼을 누르고 Thonny 편집 영역에 붙여넣습니다(Ctrl+V). 그다음 wifi_test.py로 피코에 저장하고 실행(▶)하세요.

복사가 안 되면 선생님이 올려둔 3-1_wifi_connect.py 파일을 받아서 열면 됩니다.

import network
import time
from wifi_config import WIFI_SSID, WIFI_PASSWORD

wlan = network.WLAN(network.STA_IF)   # 와이파이 장치 준비
wlan.active(True)                     # 켜기

print("연결 중...")
wlan.connect(WIFI_SSID, WIFI_PASSWORD)

wait = 0
while not wlan.isconnected():      # 연결될 때까지 기다리기
    print("  대기", wait, "초")
    time.sleep(1)
    wait += 1
    if wait > 15:
        print("연결 실패. wifi_config.py를 확인하세요.")
        raise SystemExit

ip = wlan.ifconfig()[0]
print("연결 성공!  IP:", ip)

while True:
    rssi = wlan.status('rssi')
    print(rssi, "dBm")
    time.sleep(1)

보통 3~8초쯤 "대기"가 찍히다가 연결 성공과 IP 주소가 나옵니다. 그 뒤로 1초마다 RSSI가 흘러가요.

코드 읽기

  • from wifi_config import ... — 아까 만든 비밀 파일에서 이름과 비밀번호를 가져옵니다
  • wlan.connect() — 연결을 시도합니다. 바로 되는 게 아니라 시간이 걸려요
  • while not wlan.isconnected() — 될 때까지 1초씩 기다립니다. 15초 넘으면 포기
  • wlan.ifconfig()[0] — 공유기가 피코에게 준 주소(IP)입니다. 다음 시간에 씁니다. 학교와 집에서 각각 다른 주소를 받습니다
  • wlan.status('rssi') — 지금 신호 세기
IP 주소를 메모해 두세요

192.168.0.23 같은 숫자입니다. 다음 시간에 폰으로 피코에 접속할 때 이 주소를 칩니다. 같은 와이파이 안에서도 피코마다 다르고, 집에 가면 또 달라집니다.

활동 3. 주변 와이파이 둘러보기

목표 — 우리 교실에서 몇 개의 와이파이가 잡히는지 본다

피코는 연결하지 않은 와이파이도 볼 수 있습니다. 셸에서 아래를 한 줄씩 쳐 보세요.

import network
wlan = network.WLAN(network.STA_IF)
wlan.active(True)

for ap in wlan.scan():
    print(ap[0].decode(), ap[3], "dBm")

이름과 신호 세기가 줄줄이 나옵니다. 옆 반, 다른 층, 학교 밖 것까지요. 이름이 비어 있는 건 숨김 설정을 한 와이파이입니다.

ap[0]이 이름, ap[3]이 RSSI예요. 하나의 와이파이 정보가 여러 칸으로 묶여 있어서 번호로 꺼냅니다.

활동 4. 우리 교실 신호 지도

목표 — 교실과 복도를 돌며 재고, 핫플레이스와 콜드플레이스를 찾는다

활동 2 코드를 돌려둔 채로 노트북과 피코를 들고 교실 안을 돕니다. 혼자 다 재지 말고 모둠별로 구역을 나누세요. 각 장소에서 10초쯤 서서 값이 안정되길 기다린 뒤 기록하세요.

1
공유기(AP) 앞에서

교실 공유기가 어디 붙어 있는지 먼저 찾으세요. 천장이나 벽 위쪽에 있는 경우가 많습니다. 여기가 기준점이고, 가장 강한 값이 나와야 정상이에요.

2
교실 구석구석

앞줄·뒷줄, 창가·복도 쪽, 교탁 앞, 사물함 뒤, 교실 문 밖 복도. 문을 닫았을 때와 열었을 때가 다른지도 봐 두세요.

기록에 와이파이 비밀번호는 적지 마세요. 코드를 어딘가에 올릴 때도 wifi_config.py만은 빼야 합니다.

점검하기

RSSI -45와 -80 중 어느 쪽이 강한 신호인가요?
-45입니다. RSSI는 0에 가까울수록 강합니다. 숫자의 크기가 아니라 0과의 거리로 봅니다.
와이파이 비밀번호를 왜 별도 파일에 두나요?
코드를 공유하거나 깃허브에 올릴 때 비밀번호가 같이 새어나가지 않게 하기 위해서입니다. 나중에 API 키를 다룰 때도 같은 원칙을 씁니다.
연결이 계속 안 될 때 가장 먼저 확인할 것은?
와이파이 이름에 5G가 붙어 있는지입니다. 피코는 2.4GHz만 지원합니다.
wlan.ifconfig()[0]이 알려주는 것은?
공유기가 피코에게 배정한 IP 주소입니다. 같은 와이파이 안의 다른 기기(폰 등)가 피코를 찾을 때 이 주소를 씁니다.
RSSI가 강하면 인터넷도 빠른가요?
꼭 그렇진 않습니다. RSSI는 공유기와 피코 사이의 신호 세기일 뿐이고, 인터넷 속도는 공유기 뒤의 회선, 동시 접속자 수 등에 따라 달라집니다. 센서가 재는 것과 알고 싶은 것이 다른 또 하나의 예입니다.
