폰으로 보는 피코

피코를 작은 웹서버로 만듭니다. 그러면 노트북 없이, 스마트폰 브라우저에서 피코의 값을 볼 수 있어요. 오늘 만든 페이지는 같은 와이파이를 쓰는 가족 누구나 열어볼 수 있습니다.

누를 때마다 피코가 새 값을 보내줍니다. 저절로 바뀌지는 않아요. 왜 그런지 아래에서 알아봅니다.

지난 시간 복습

0. 돌아보기 — 3차시 자료
  • 비밀번호는 wifi_config.py에 따로. 오늘도 그 파일을 그대로 씁니다
  • wlan.connect() 뒤에 isconnected()가 될 때까지 기다린다
  • RSSI는 마이너스, 0에 가까울수록 강함
  • 피코는 2.4GHz만. 5G 붙은 와이파이는 안 됨
시작 전 확인

지난 시간에 메모한 IP 주소를 꺼내두세요. 그리고 스마트폰이 피코와 같은 와이파이에 붙어 있는지 확인하세요. 폰이 5G 쪽에 붙어 있으면 이름을 2.4GHz 쪽으로 바꿔야 합니다. 이것 때문에 안 되는 경우가 제일 많아요.

서버란 무엇인가

1. 돌아보기

여러분이 브라우저에 주소를 치면, 어딘가에 있는 컴퓨터가 "이 페이지 줘"라는 요청을 받고 페이지를 만들어 응답합니다. 그 컴퓨터를 서버라고 불러요.

스마트폰주소 입력 = 요청
▶
피코페이지 만들기
◀
스마트폰화면에 표시 = 응답

오늘 피코가 그 서버가 됩니다. 폰이 피코의 IP 주소로 요청을 보내면, 피코가 지금 신호 세기와 온도를 담은 페이지를 만들어 돌려줍니다.

기억할 것 두 가지

같은 와이파이 안에서만 됩니다. 피코의 IP는 우리 집 공유기가 준 주소라서, 밖에서는 못 찾아요. 학교에서 우리 집 피코에 접속하는 건 안 됩니다.

새로고침해야 갱신됩니다. 서버는 요청이 올 때만 일합니다. 페이지를 열어둔 채 기다려도 값은 안 바뀌어요. 맨 위 화면에서 버튼을 눌러본 이유가 이겁니다.

활동 1. 서버 띄우고 폰으로 접속

목표 — 피코가 만든 페이지를 스마트폰에서 연다

코드가 좀 깁니다. 지금은 전부 이해하지 않아도 됩니다. 먼저 돌려보고, 다음 활동에서 필요한 부분만 뜯어봅니다.

직접 다 치지 말고 선생님이 나눠준 4-1_server.py 파일을 여세요. 그 파일을 Raspberry Pi Pico에 server.py라는 이름으로 저장하면 됩니다. 아래는 같은 내용이니 눈으로 따라 읽어 보세요.

import network
import socket
import time
from wifi_config import WIFI_SSID, WIFI_PASSWORD

# ── 와이파이 연결 (지난 시간과 같음) ──
wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.connect(WIFI_SSID, WIFI_PASSWORD)

wait = 0
while not wlan.isconnected():
    time.sleep(1)
    wait += 1
    if wait > 15:
        print("연결 실패")
        raise SystemExit

my_ip = wlan.ifconfig()[0]
print("연결 완료  http://" + my_ip)

# ── 페이지 만들기 ──
def make_page():
    rssi = wlan.status('rssi')
    uptime = time.ticks_ms() // 1000
    return f"""<!DOCTYPE html>
<html><head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Pico 모니터</title>
<style>
  body {{ font-family: sans-serif; background: #0f0f23; color: #ccc;
         padding: 20px; text-align: center; }}
  h1 {{ color: #00d4ff; font-size: 1.4em; }}
  .grid {{ display: grid; grid-template-columns: 1fr 1fr; gap: 12px;
           max-width: 400px; margin: 20px auto; }}
  .card {{ background: #1a1a3e; border-radius: 12px; padding: 18px; }}
  .label {{ color: #888; font-size: 0.8em; }}
  .value {{ color: #00d4ff; font-size: 1.4em; font-weight: bold; }}
</style>
</head><body>
<h1>Pico Wi-Fi 모니터</h1>
<div class="grid">
  <div class="card"><div class="label">Wi-Fi 신호</div>
       <div class="value">{rssi} dBm</div></div>
  <div class="card"><div class="label">IP 주소</div>
       <div class="value" style="font-size:1em">{my_ip}</div></div>
  <div class="card"><div class="label">가동 시간</div>
       <div class="value">{uptime}초</div></div>
  <div class="card"><div class="label">만든 사람</div>
       <div class="value">이름</div></div>
</div>
<p style="color:#666;font-size:0.8em">새로고침하면 데이터가 업데이트됩니다</p>
</body></html>"""

# ── 서버 시작 ──
server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
server.bind(('0.0.0.0', 80))
server.listen(2)
print("서버 시작. 폰에서 위 주소로 접속하세요.")

while True:
    try:
        client, addr = server.accept()      # 누가 접속할 때까지 기다림
        request = client.recv(1024)
        if b'favicon' in request:            # 브라우저 아이콘 요청은 무시
            client.close()
            continue
        print("접속:", addr[0])
        client.send(b"HTTP/1.1 200 OK\r\nContent-Type: text/html; charset=utf-8\r\nConnection: close\r\n\r\n")
        client.send(make_page().encode())
        client.close()
    except Exception as e:
        print("에러:", e)
        try:
            client.close()
        except:
            pass

실행하고 주소 확인

셸에 연결 완료 http://192.168.x.x가 뜹니다. 이 주소가 오늘의 핵심이에요.

2
폰 브라우저에 주소 입력

검색창이 아니라 주소창에 http://192.168.x.x를 그대로 칩니다. 검색하면 구글로 갑니다.

3
셸에서 "접속:" 확인

폰에서 페이지가 열리는 순간 토니 셸에 접속: 192.168.x.y가 찍힙니다. 폰의 주소예요. 피코가 폰의 요청을 받았다는 증거입니다.

4
가족 폰으로도

같은 와이파이에 있는 다른 폰이나 태블릿에서도 열어보세요. 셸에 접속 기록이 하나 더 찍힙니다.

활동 2. 내 페이지로 만들기

목표 — HTML 부분을 고쳐 나만의 페이지를 만든다

코드 가운데 make_page() 안의 큰따옴표 세 개 사이가 HTML입니다. 브라우저가 화면을 그리는 언어예요. 이 부분만 고치면 페이지가 바뀝니다.

1
이름 넣기

<div class="value">이름</div>에서 "이름"을 본인 이름으로. 저장 → 정지 → 다시 실행 → 폰 새로고침.

2
색 바꾸기

#00d4ff가 하늘색입니다. #ff6b6b(빨강), #7ce05a(초록)로 바꿔 보세요. 여섯 자리 중 앞 둘이 빨강, 가운데가 초록, 뒤가 파랑의 양입니다.

3
제목 바꾸기

<h1>Pico Wi-Fi 모니터</h1>를 마음대로. "○○이의 피코"처럼요.

중괄호가 두 개인 이유

HTML 안에 {{ }}가 두 겹으로 보일 거예요. 이 문자열은 파이썬 f-string이라 {rssi}처럼 한 겹은 "여기에 변수 값을 넣어라"는 뜻입니다. CSS에서 진짜 중괄호를 쓰려면 두 겹으로 써야 해요. 한 겹으로 고치면 에러가 납니다.

활동 3. 온도 카드 추가하기

목표 — 2차시 온도 센서를 페이지에 붙인다

2차시에 만든 온도 읽기를 이 페이지에 넣습니다. 세 군데를 고칩니다.

① 맨 위 import 아래에 센서 준비를 추가합니다.

from machine import ADC
sensor = ADC(4)

def read_temp():
    volt = sensor.read_u16() * 3.3 / 65535
    return round(27 - (volt - 0.706) / 0.001721, 1)

② make_page() 안, uptime 줄 아래에 온도를 읽는 줄을 추가합니다.

    temp = read_temp()

③ HTML의 "만든 사람" 카드 앞에 카드를 하나 더 넣습니다.

  <div class="card"><div class="label">온도</div>
       <div class="value">{temp} °C</div></div>

저장하고 다시 실행한 뒤 폰을 새로고침하면 온도 카드가 생깁니다. 피코를 손으로 감싸고 새로고침해 보세요.

방금 한 일의 의미

센서 값을 읽어서(2차시) → 네트워크로 보내고(3차시) → 화면에 보여준다(4차시). 이 세 단계가 앞으로 만들 모든 프로젝트의 뼈대입니다. 센서만 가스 센서나 조도 센서로 바꾸면 그대로 작동해요.

활동 4. 피코만 들고 다니기

목표 — 노트북 없이 신호 지도를 다시 그린다

지난 시간엔 노트북을 들고 다녔죠. 오늘은 피코만 들고 갑니다.

1
main.py로 저장

지금 코드를 파일 → 다른 이름으로 저장 → Raspberry Pi Pico → main.py. 이러면 전원만 있으면 혼자 돕니다.

2
보조배터리에 꽂기

USB를 노트북에서 뽑아 보조배터리에 꽂습니다. 내장 LED가 잠깐 반짝이면 켜진 거예요. 10초쯤 기다리면 와이파이에 붙습니다.

3
폰으로 접속해서 순회

같은 와이파이라면 주소는 지난번과 같을 가능성이 높습니다. 장소를 옮겨가며 새로고침하고 값을 봅니다. 지난 시간 지도와 비교해 보세요.

주소가 바뀌었다면

공유기가 가끔 다른 IP를 줍니다. 그럴 땐 피코를 다시 노트북에 꽂고 셸에서 주소를 확인하세요. 정지 버튼을 눌러야 셸이 돌아옵니다.

그리고 다음 시간 실습 전에는 main.py를 지우거나 이름을 바꿔 두세요. 안 그러면 케이블을 꽂을 때마다 서버가 먼저 떠서 코딩이 불편합니다.

점검하기

서버란 무엇인가요?
요청을 받으면 응답을 돌려주는 컴퓨터입니다. 오늘은 피코가 폰의 요청을 받아 HTML 페이지를 만들어 돌려줬습니다.
학교에서 우리 집 피코 페이지를 열 수 있나요?
없습니다. 피코의 IP는 집 공유기 안에서만 통하는 주소라서, 같은 와이파이에 붙은 기기만 접속할 수 있습니다.
페이지를 열어뒀는데 값이 안 변하는 이유는?
서버는 요청이 올 때만 페이지를 만듭니다. 새로고침을 해야 새 요청이 가고 새 값이 옵니다.
HTML 안의 중괄호를 두 겹으로 쓰는 이유는?
f-string에서 한 겹 중괄호는 변수 자리라는 뜻이라, CSS의 진짜 중괄호는 두 겹으로 써서 구분합니다.
main.py로 저장하면 무엇이 달라지나요?
노트북 없이 전원만 넣어도 피코가 스스로 실행합니다. 그래서 보조배터리에 꽂아 들고 다닐 수 있습니다.
