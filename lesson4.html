0. 돌아보기 — 3차시 자료

시작 전 확인

지난 시간에 메모한 IP 주소를 꺼내두세요. 그리고 스마트폰이 피코와 같은 와이파이에 붙어 있는지 확인하세요. 폰이 5G 쪽에 붙어 있으면 이름을 2.4GHz 쪽으로 바꿔야 합니다. 이것 때문에 안 되는 경우가 제일 많아요.

서버란 무엇인가

1. 돌아보기

여러분이 브라우저에 주소를 치면, 어딘가에 있는 컴퓨터가 "이 페이지 줘"라는 요청을 받고 페이지를 만들어 응답합니다. 그 컴퓨터를 서버라고 불러요.

스마트폰주소 입력 = 요청
▶
피코페이지 만들기
◀
스마트폰화면에 표시 = 응답

오늘 피코가 그 서버가 됩니다. 폰이 피코의 IP 주소로 요청을 보내면, 피코가 지금 신호 세기와 온도를 담은 페이지를 만들어 돌려줍니다.

기억할 것 두 가지

같은 와이파이 안에서만 됩니다. 피코의 IP는 우리 집 공유기가 준 주소라서, 밖에서는 못 찾아요. 학교에서 우리 집 피코에 접속하는 건 안 됩니다.

새로고침해야 갱신됩니다. 서버는 요청이 올 때만 일합니다. 페이지를 열어둔 채 기다려도 값은 안 바뀌어요. 맨 위 화면처럼 저절로 바뀌게 하려면 한 가지 장치가 더 필요한데, 그건 활동 3에서 만듭니다.

활동 1. 서버 띄우고 폰으로 접속

목표 — 피코가 만든 페이지를 스마트폰에서 연다

코드가 좀 깁니다. 지금은 전부 이해하지 않아도 됩니다. 먼저 돌려보고, 다음 활동에서 필요한 부분만 뜯어봅니다.

절대 직접 치지 마세요. 아래 [복사] 버튼을 누르고 Thonny에 붙여넣은 뒤(Ctrl+V), Raspberry Pi Pico에 server.py로 저장하고 실행(▶)합니다.

복사가 안 되면 선생님이 올려둔 4-1_server.py 파일을 받아서 여세요. 코드는 지금 다 이해하지 않아도 됩니다. 눈으로 훑으면서 아는 부분만 찾아보세요.

import network
import socket
import time
from wifi_config import WIFI_SSID, WIFI_PASSWORD

# ── 와이파이 연결 (지난 시간과 같음) ──
wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.connect(WIFI_SSID, WIFI_PASSWORD)

wait = 0
while not wlan.isconnected():
    time.sleep(1)
    wait += 1
    if wait > 15:
        print("연결 실패")
        raise SystemExit

my_ip = wlan.ifconfig()[0]
print("연결 완료  http://" + my_ip)

# ── 페이지 만들기 ──
def make_page():
    rssi = wlan.status('rssi')
    uptime = time.ticks_ms() // 1000
    return f"""<!DOCTYPE html>
<html><head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Pico 모니터</title>
<style>
  body {{ font-family: sans-serif; background: #0f0f23; color: #ccc;
         padding: 20px; text-align: center; }}
  h1 {{ color: #00d4ff; font-size: 1.4em; }}
  .grid {{ display: grid; grid-template-columns: 1fr 1fr; gap: 12px;
           max-width: 400px; margin: 20px auto; }}
  .card {{ background: #1a1a3e; border-radius: 12px; padding: 18px; }}
  .label {{ color: #888; font-size: 0.8em; }}
  .value {{ color: #00d4ff; font-size: 1.4em; font-weight: bold; }}
</style>
</head><body>
<h1>Pico Wi-Fi 모니터</h1>
<div class="grid">
  <div class="card"><div class="label">Wi-Fi 신호</div>
       <div class="value">{rssi} dBm</div></div>
  <div class="card"><div class="label">IP 주소</div>
       <div class="value" style="font-size:1em">{my_ip}</div></div>
  <div class="card"><div class="label">가동 시간</div>
       <div class="value">{uptime}초</div></div>
  <div class="card"><div class="label">만든 사람</div>
       <div class="value">이름</div></div>
</div>
<p style="color:#666;font-size:0.8em">새로고침하면 데이터가 업데이트됩니다</p>
</body></html>"""

# ── 서버 시작 ──
server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
server.bind(('0.0.0.0', 80))
server.listen(2)
print("서버 시작. 폰에서 위 주소로 접속하세요.")

while True:
    try:
        client, addr = server.accept()      # 누가 접속할 때까지 기다림
        request = client.recv(1024)
        if b'favicon' in request:            # 브라우저 아이콘 요청은 무시
            client.close()
            continue
        print("접속:", addr[0])
        client.send(b"HTTP/1.1 200 OK\r\nContent-Type: text/html; charset=utf-8\r\nConnection: close\r\n\r\n")
        client.send(make_page().encode())
        client.close()
    except Exception as e:
        print("에러:", e)
        try:
            client.close()
        except:
            pass

폰에서 페이지가 열리는 순간 토니 셸에 접속: 192.168.x.y가 찍힙니다. 폰의 주소예요. 피코가 폰의 요청을 받았다는 증거입니다.

활동 2. 내 페이지로 만들기

목표 — HTML 부분을 고쳐 나만의 페이지를 만든다

코드 가운데 make_page() 안의 큰따옴표 세 개 사이가 HTML입니다. 브라우저가 화면을 그리는 언어예요. 이 부분만 고치면 페이지가 바뀝니다.

1
이름 넣기

<div class="value">이름</div>에서 "이름"을 본인 이름으로. 저장 → 정지 → 다시 실행 → 폰 새로고침.

2
색 바꾸기

#00d4ff가 하늘색입니다. #ff6b6b(빨강), #7ce05a(초록)로 바꿔 보세요. 여섯 자리 중 앞 둘이 빨강, 가운데가 초록, 뒤가 파랑의 양입니다.

3
제목 바꾸기

<h1>Pico Wi-Fi 모니터</h1>를 마음대로. "○○이의 피코"처럼요.

중괄호가 두 개인 이유

HTML 안에 {{ }}가 두 겹으로 보일 거예요. 이 문자열은 파이썬 f-string이라 {rssi}처럼 한 겹은 "여기에 변수 값을 넣어라"는 뜻입니다. CSS에서 진짜 중괄호를 쓰려면 두 겹으로 써야 해요. 한 겹으로 고치면 에러가 납니다.

활동 3. 저절로 갱신되게 만들기

목표 — 새로고침 없이 값이 바뀌는 진짜 대시보드로

지금은 값을 볼 때마다 새로고침을 눌러야 합니다. 피코를 들고 걸어다니면서 폰을 계속 누르기는 번거롭죠. 화면이 알아서 갱신되면 훨씬 좋을 겁니다.

HTML의 <head> 안에 이 한 줄만 넣으면 됩니다.

<meta http-equiv="refresh" content="5">

"5초마다 이 페이지를 다시 불러와라"는 뜻입니다. <title> 줄 바로 위에 넣고 저장한 뒤, 정지 → 다시 실행 → 폰에서 페이지를 한 번만 새로고침하세요.

이제 가만히 두고 보세요. 5초마다 가동 시간이 늘어나고 신호 세기가 바뀝니다. 피코를 들고 걸어가면 화면이 따라옵니다.

서버가 바뀐 게 아닙니다

피코 코드는 그대로예요. 달라진 건 브라우저입니다. "5초마다 다시 요청하라"는 지시를 페이지 안에 넣었더니, 폰이 알아서 계속 물어보는 거죠. 여전히 서버는 요청이 올 때만 일합니다.

숫자를 바꿔 보세요

content="1"로 하면 1초마다 갱신됩니다. 더 생생하지만 피코가 그만큼 자주 일해야 하고, 화면이 깜빡여서 오히려 보기 불편할 수 있어요. 1, 3, 5, 10을 모두 시험해 보고 내가 쓰기 좋은 숫자를 고르세요. 정답은 없습니다.

활동 4. AI에게 그래프를 부탁하기

목표 — 원하는 걸 AI에게 설명하고, 받은 코드를 검증한다

숫자만 보면 "지금 강한지 약한지"는 알아도 "아까보다 좋아졌는지"는 모릅니다. 최근 값들이 막대로 쌓이면 한눈에 보이겠죠.

이번엔 직접 짜지 말고 AI에게 부탁합니다. 이렇게 요청하는 방식을 바이브 코딩이라고 해요.

이렇게 물어보세요

지금 피코가 소켓 웹서버로 와이파이 신호 세기(rssi)를 보여주는 페이지를 만들고 있어. 여기에 최근 20개 값을 막대그래프로 보여주는 기능을 추가해 줘.

외부 라이브러리 없이, 마이크로파이썬에서 돌아가게 해 줘. 그리고 어느 부분을 고쳐야 하는지 알려 줘.

그냥 "그래프 만들어줘"라고 하면 엉뚱한 코드가 옵니다. 지금 내 상황과 원하는 것을 같이 말해야 쓸 만한 답이 나와요.

받은 코드를 그대로 믿지 마세요

AI가 준 코드는 꽤 자주 안 돌아갑니다. 마이크로파이썬에 없는 기능을 쓰거나, 들여쓰기가 어긋나거나, 우리 코드와 변수 이름이 다르거나요. 에러가 나면 이렇게 하세요.

1
에러 메시지 마지막 줄을 읽는다

에러 이름과 몇 번째 줄인지가 적혀 있습니다. 무슨 뜻인지 몰라도 괜찮으니 일단 읽으세요.

2
에러를 그대로 붙여넣고 다시 묻는다

"이런 에러가 나" 하고 메시지를 통째로 복사해 주세요. 말로 설명하는 것보다 훨씬 정확합니다.

3
그래도 안 되면 질문을 쪼갠다

"전체를 고쳐줘"가 아니라 "이 다섯 줄이 무슨 뜻인지 설명해줘"로 바꿔 보세요.

AI는 내 피코를 보지 못합니다

AI는 여러분의 화면도, 에러 메시지도, 지금 어떤 코드가 돌아가는지도 모릅니다. 우리가 알려준 것만 알아요. 잘 물어보는 것이 실력인 이유입니다.

그리고 AI가 준 코드를 이해하지 못한 채 붙여넣으면, 나중에 고장났을 때 아무것도 할 수 없습니다. 최소한 어느 부분이 무슨 일을 하는지는 짚고 넘어가세요.

완성되면

막대가 20개 쌓이고 5초마다 오른쪽으로 밀려납니다. 피코를 들고 교실 뒤로 걸어가면 막대가 점점 낮아지는 게 보일 거예요. 이게 대시보드입니다.

여유가 있으면 색도 바꿔 보세요. 신호가 좋으면 초록, 나쁘면 빨강처럼요. 그것도 AI에게 부탁하면 됩니다.

활동 5. 피코만 들고 다니기

목표 — 노트북 없이 신호 지도를 다시 그린다

1

2
보조배터리에 꽂기

3
폰으로 접속해서 순회

같은 와이파이라면 주소는 지난번과 같을 가능성이 높습니다. 장소를 옮겨가며 새로고침하고 값을 봅니다. 지난 시간 지도와 비교해 보세요.

주소가 바뀌었다면

공유기가 가끔 다른 IP를 줍니다. 그럴 땐 피코를 다시 노트북에 꽂고 셸에서 주소를 확인하세요. 정지 버튼을 눌러야 셸이 돌아옵니다.

그리고 다음 시간 실습 전에는 main.py를 지우거나 이름을 바꿔 두세요. 안 그러면 케이블을 꽂을 때마다 서버가 먼저 떠서 코딩이 불편합니다.

내가 고친 부분은 코드를 그대로 붙여넣어도 좋습니다. 단 비밀번호는 절대 붙여넣지 마세요. 코드 안에 비밀번호가 직접 들어 있지 않은지 한 번 더 확인합니다.

점검하기

서버란 무엇인가요?
요청을 받으면 응답을 돌려주는 컴퓨터입니다. 오늘은 피코가 폰의 요청을 받아 HTML 페이지를 만들어 돌려줬습니다.
학교에서 우리 집 피코 페이지를 열 수 있나요?
없습니다. 피코의 IP는 집 공유기 안에서만 통하는 주소라서, 같은 와이파이에 붙은 기기만 접속할 수 있습니다.
페이지를 열어뒀는데 값이 안 변하는 이유는?
서버는 요청이 올 때만 페이지를 만듭니다. 새로고침을 해야 새 요청이 가고 새 값이 옵니다.
HTML 안의 중괄호를 두 겹으로 쓰는 이유는?
f-string에서 한 겹 중괄호는 변수 자리라는 뜻이라, CSS의 진짜 중괄호는 두 겹으로 써서 구분합니다.
meta refresh를 넣으면 무엇이 달라지나요?
브라우저가 정해진 시간마다 스스로 페이지를 다시 요청합니다. 피코 코드가 바뀐 게 아니라, 요청을 자동으로 반복하게 만든 것입니다.
AI에게 코드를 부탁할 때 왜 "지금 내 상황"을 함께 말해야 하나요?
AI는 내 화면도 내 코드도 보지 못하기 때문입니다. 알려준 것만 알고 나머지는 추측하므로, 상황을 빼면 엉뚱한 코드가 옵니다.
main.py로 저장하면 무엇이 달라지나요?
노트북 없이 전원만 넣어도 피코가 스스로 실행합니다. 그래서 보조배터리에 꽂아 들고 다닐 수 있습니다.
