활동 2. 색을 보고 LED 색 바꾸기

목표 — ID 번호를 색으로 바꾼다

빨간 물건을 보여주면 LED가 빨강, 초록을 보여주면 초록이 되게 합니다.

from huskylensPythonLibrary import HuskyLensLibrary
from machine import Pin
from neopixel import NeoPixel
import time

TIMING = (280, 515, 515, 745)
LED_COUNT = 10                   # ★ 스틱 10, 스트립 60
led = NeoPixel(Pin(16), LED_COUNT, timing=TIMING)

# ★ 학습한 ID 번호 -> 켤 색  (내 학습 순서에 맞게 바꾸세요)
COLORS = {
    1: (60, 0, 0),     # ID1 -> 빨강
    2: (0, 60, 0),     # ID2 -> 초록
    3: (0, 0, 60),     # ID3 -> 파랑
}


def fill(color):
    for i in range(LED_COUNT):
        led[i] = color
    led.write()


husky = HuskyLensLibrary("I2C")
time.sleep(0.5)
husky.color_recognition_mode()
time.sleep(0.5)
print("색 인식 시작!")

while True:
    result = husky.command_request_blocks()

    # 학습된 것(ID 1 이상)만 고르기
    learned = [b for b in result if b[4] > 0]

    if learned:
        # 여러 개가 보이면 가장 큰 덩어리를 고른다 (w x h 가 가장 큰 것)
        biggest = max(learned, key=lambda b: b[2] * b[3])
        color_id = biggest[4]
        fill(COLORS.get(color_id, (30, 30, 30)))   # 표에 없는 ID 는 흰색
        print("ID", color_id)
    else:
        fill((0, 0, 0))

    time.sleep(0.2)

활동 3. 얼굴을 따라오는 불빛

목표 — 위치(x)를 LED 칸 번호로 바꾼다

기능을 다시 Face Recognition으로 돌려 두세요. 이번엔 ID를 쓰지 않으니 학습하지 않아도 됩니다. 얼굴이 화면 어디에 있는지만 씁니다.

from huskylensPythonLibrary import HuskyLensLibrary
from machine import Pin
from neopixel import NeoPixel
import time

TIMING = (280, 515, 515, 745)
LED_COUNT = 10                   # ★ 스틱 10, 스트립 60
led = NeoPixel(Pin(16), LED_COUNT, timing=TIMING)

husky = HuskyLensLibrary("I2C")
time.sleep(0.5)
husky.face_recognition_mode()
time.sleep(0.5)
print("얼굴을 좌우로 움직여 보세요!")

while True:
    result = husky.command_request_blocks()

    for i in range(LED_COUNT):           # 일단 전부 끄고
        led[i] = (0, 0, 0)

    if result:
        x = result[0][0]                 # 첫 번째 얼굴의 x 위치
        idx = x * LED_COUNT // 320       # 0~320 을 0~(칸수-1) 로 바꾸기
        if idx >= LED_COUNT:
            idx = LED_COUNT - 1

        # idx = LED_COUNT - 1 - idx      # ★ 방향이 반대면 맨 앞 # 를 지우세요

        led[idx] = (0, 40, 60)           # 하늘색 한 칸
        print("x =", x, "-> LED", idx, "번")

    led.write()
    time.sleep(0.1)

숫자 바꾸기 — 이 줄이 핵심

idx = x * LED_COUNT // 320

허스키렌즈 화면 가로는 0~320, LED 스틱은 0~9번입니다. 화면을 10칸으로 나눠서 얼굴이 몇 번째 칸에 있는지 계산하는 거예요. //는 나눈 뒤 소수점을 버리는 나눗셈입니다.

얼굴 위치 x계산켜지는 LED
0 (왼쪽 끝)0 × 10 // 3200번
1001000 // 3203번
160 (가운데)1600 // 3205번
319 (오른쪽 끝)3190 // 3209번

6차시에 센서 값 0~65535를 0~100%로 바꿨던 것과 같은 생각입니다. 한 범위의 숫자를 다른 범위로 옮기기. 피지컬 컴퓨팅에서 가장 많이 쓰는 계산이에요.

내가 오른쪽으로 갔는데 불빛은 왼쪽으로 간다면

카메라가 나를 마주 보고 있으면 좌우가 거울처럼 바뀝니다. 코드에서 # idx = LED_COUNT - 1 - idx 줄 맨 앞의 #을 지우세요. 0번은 9번으로, 9번은 0번으로 뒤집힙니다.

w는 진짜 거리가 아닙니다

w는 '화면에서 얼굴이 차지하는 너비'일 뿐입니다. 얼굴이 작은 사람, 고개를 돌린 사람은 같은 거리라도 w가 다르게 나와요. 그래서 이 게이지는 cm를 재는 장치가 아니라 "가까워졌다 / 멀어졌다"를 알려주는 장치입니다. 진짜 거리가 필요하면 초음파 센서 같은 다른 센서를 써야 해요. 이런 차이를 설명할 수 있는 것이 센서 이해입니다.

모범 답안 펼쳐 보기 (먼저 스스로 해 보세요) 
from huskylensPythonLibrary import HuskyLensLibrary
from machine import Pin
from neopixel import NeoPixel
import time

TIMING = (280, 515, 515, 745)
LED_COUNT = 10                   # ★ 스틱 10, 스트립 60
led = NeoPixel(Pin(16), LED_COUNT, timing=TIMING)

FAR = 30       # ★ 멀리 있을 때 w 값  (셸에 찍히는 값을 보고 정하기)
NEAR = 180     # ★ 아주 가까이 있을 때 w 값

husky = HuskyLensLibrary("I2C")
time.sleep(0.5)
husky.face_recognition_mode()
time.sleep(0.5)

while True:
    result = husky.command_request_blocks()
    n = 0
    w = 0
    if result:
        w = result[0][2]                              # 상자 너비
        n = (w - FAR) * LED_COUNT // (NEAR - FAR)
        if n < 0:
            n = 0
        if n > LED_COUNT:
            n = LED_COUNT

    for i in range(LED_COUNT):
        if i < n:
            if n >= LED_COUNT * 0.8:
                led[i] = (60, 0, 0)       # 너무 가까움 -> 빨강
            else:
                led[i] = (0, 50, 20)      # 적당함 -> 초록
        else:
            led[i] = (0, 0, 0)
    led.write()

    print("w =", w, "->", n, "칸")
    time.sleep(0.1)

선 추적만 다릅니다. 상자가 아니라 화살표라서 command_request_blocks() 대신 command_request_arrows()로 받고, 값도 [시작 x, 시작 y, 끝 x, 끝 y, ID] 모양입니다. algorthim은 철자가 틀린 것 같지만 라이브러리 이름 그대로 써야 합니다.

'사물 인식'과 '물체 분류'는 다릅니다

사물 인식은 공장에서 미리 배운 20가지만 압니다. 연필이나 필통은 목록에 없어서 아무리 비춰도 모릅니다.

물체 분류는 내가 직접 가르칩니다. 연필이든 필통이든 학습시키면 구분해요. 대신 내가 가르친 것 말고는 모르고, 가르친 것 중 가장 비슷한 것으로 대답해 버릴 수 있습니다.

얼굴이 x = 240에 있을 때, LED 10칸 중 몇 번이 켜지나요?
240 × 10 // 320 = 2400 // 320 = 7. 7번 LED가 켜집니다.
여러 가지를 구분해서 학습하려면 무엇을 켜야 하나요?
그 기능의 설정에서 Learn Multiple을 켜고 Save & Return으로 저장해야 합니다. 설정은 기능마다 따로입니다.
w로 거리를 짐작할 때의 한계는?
w는 화면 속 얼굴 너비라서 얼굴 크기나 고개 각도에 따라 달라집니다. 가까워졌다/멀어졌다는 알 수 있지만 정확한 cm는 알 수 없습니다.
사물 인식과 물체 분류의 차이는?
사물 인식은 미리 배운 20가지만 알아보고, 물체 분류는 내가 직접 가르친 것을 구분합니다.
허스키렌즈 코드를 AI에게 부탁할 때 꼭 함께 알려줘야 하는 것은?
우리가 쓰는 라이브러리 사용법(불러오는 방법, 함수 이름, 돌려주는 값의 모양)과 LED의 TIMING 문장입니다. AI는 우리 라이브러리와 부품을 모릅니다.
