0. 돌아보기 — 부품을 만지기 전에

LED는 어떻게 빛을 낼까

LED 안에는 성질이 다른 두 반도체가 맞붙어 있습니다. 전기를 흘리면 그 경계에서 전자가 만나면서 에너지 차이만큼 빛이 나옵니다. 이 차이가 크면 파란 계열, 작으면 붉은 계열이 돼요.

색이 다른 이유가 '색깔 있는 플라스틱' 때문이 아니라 재료 자체가 달라서라는 게 핵심입니다.

RGB LED — 세 개가 한 몸에

하나의 알갱이 안에 빨강(R)·초록(G)·파랑(B) 세 개의 LED가 같이 들어 있는 것을 RGB LED라고 합니다. 빛의 삼원색 원리로, 셋의 밝기를 조절하면 수많은 색을 만들 수 있어요.

각 색은 0~255 단계로 조절합니다. 우리가 코드에 쓰는 (255, 120, 0)이 바로 그 세 숫자예요. 컴퓨터 모니터도, 휴대폰 화면도 같은 방식으로 색을 만듭니다.

네오픽셀 — 칩이 들어 있는 스마트 LED

우리가 쓰는 건 그냥 RGB LED가 아니라 네오픽셀(NeoPixel)입니다. LED 알갱이마다 제어 칩이 하나씩 들어 있어요.

덕분에 신호선 딱 한 가닥으로 수십 개를 각각 다르게 제어할 수 있습니다. 첫 번째 칸이 자기 몫만 가져가고 나머지를 옆으로 넘기는 방식이에요. 그래서 코드에서 번호를 붙여 부릅니다.

led[0] = (255, 0, 0)     # 첫 번째 칸
led[1] = (0, 255, 0)     # 두 번째 칸
led[9] = (0, 0, 255)     # 열 번째 칸

번호는 0부터 시작합니다. 10칸짜리면 0번부터 9번까지예요.

VCC, GND는 신경 안 써도 될까?

부품이 작동하려면 최소 세 가닥이 필요합니다. 전기가 들어가는 VCC(전원), 돌아 나오는 GND(접지), 그리고 명령을 주고받는 신호선이에요. 물이 흐르려면 들어가는 관과 나가는 관이 다 있어야 하는 것과 같습니다.

브레드보드로 만들면 이 세 가닥을 하나씩 꽂아야 하고, 순서를 틀리면 부품이 탑니다. 우리가 쓰는 그로브 케이블은 이 세 가닥이 한 묶음으로 들어 있고 커넥터 방향이 하나뿐이라, 잘못 꽂을 수가 없습니다.

그러니까 신경 쓸 필요가 없어진 게 아니라, 이미 안에서 다 연결되어 있는 겁니다. 나중에 그로브가 아닌 부품을 쓰게 되면 그때는 직접 맞춰야 해요.

교과서와 비교해 보기

교과서에는 같은 내용이 ESP32라는 다른 보드로 설명되어 있습니다. 보드와 핀 번호는 다르지만 원리는 완전히 같아요. LED 발광 원리, RGB 조합, 네오픽셀 구조는 그대로 읽으시면 됩니다.

0. 오늘 가장 중요한 것

지금까지는 피코 혼자 일했습니다. 오늘부터는 바깥 부품을 연결해요. 그 다리 역할을 하는 게 그로브 쉴드입니다.

브레드보드로 선을 하나씩 꽂는 대신, 케이블을 딸깍 꽂기만 하면 전원과 신호선이 한 번에 연결됩니다. 방향이 하나뿐이라 반대로 꽂을 수가 없어요.

포트는 세 종류입니다

포트이름무엇을 꽂나코드에서
디지털D16 D18 D20켜짐/꺼짐 신호를 주고받는 부품Pin(16)

포트 이름은 '어디에 꽂는가'이고, 코드에서 부를 때는 그 옆에 적힌 GP 번호를 씁니다. D16은 Pin(16), A0은 Pin(26)이에요.

쉴드 위에 작은 슬라이드 스위치가 있습니다. 3.3V가 아니라 5V로 두세요. LED와 MQ2 히터가 둘 다 5V를 필요로 합니다. 이걸 안 바꾸면 LED가 아예 안 켜지거나 색이 이상합니다.

1교시활동 1. LED 한 칸 켜기

목표 — 원하는 칸에 원하는 색을 켠다
1
연결

그로브 케이블로 LED를 쉴드의 D16 포트에 꽂습니다. 전원 스위치는 5V. USB를 노트북에 연결하세요.

2
코드 실행

아래 코드를 led.py로 피코에 저장하고 실행합니다.

from machine import Pin
from neopixel import NeoPixel
import time

# WS2813 전용 타이밍 - 빼먹으면 작동 안 함!
TIMING = (280, 515, 515, 745)
LED_COUNT = 10          # 스틱 10, 스트립 60

led = NeoPixel(Pin(16), LED_COUNT, timing=TIMING)

led[0] = (255, 0, 0)     # 첫 칸을 빨강으로
led.write()                # 실제로 보내기
TIMING은 왜 필요할까

이 LED는 신호선이 딱 한 가닥입니다. 그러면 0과 1을 어떻게 구분할까요? 신호가 지속되는 시간의 길이로 구분합니다. 짧으면 0, 길면 1인 식이죠.

그 '짧고 긴' 정확한 길이가 부품마다 다릅니다. 우리가 쓰는 WS2813에 맞는 값이 (280, 515, 515, 745)예요. LED가 이상하면 이 줄부터 확인하세요.

write()를 빠뜨리면 아무 일도 안 일어납니다

led[0] = ...는 "이렇게 하고 싶다"고 메모만 해둔 상태예요. led.write()를 불러야 실제로 전달됩니다. 오늘 가장 많이 나올 실수입니다.

내 부품에 맞게 LED_COUNT 고치기

스틱(짧고 딱딱한 막대)은 10칸, 스트립(길고 휘어지는 줄)은 60칸입니다. 숫자를 틀리게 써도 앞쪽은 켜지지만, 정확히 맞춰야 뒤쪽까지 제어됩니다.

2교시활동 4. 가스 센서 연결하기

목표 — 센서 값을 읽고 예열을 관찰한다

이번엔 반대입니다. LED는 피코가 바깥으로 내보내는 부품이었고, 센서는 바깥에서 피코로 들어오는 부품이에요.

MQ2를 A0 포트에 꽂으세요. 연결하면 센서에서 희미한 주황색 빛이 보이고 살짝 따뜻해집니다. 안쪽 히터가 달궈지는 중이라 정상이에요.

from machine import ADC, Pin
import time

gas = ADC(Pin(26))       # A0 포트

while True:
    print(gas.read_u16())
    time.sleep(1)

2차시 온도 센서와 똑같은 방법입니다. read_u16()으로 0~65535 사이 숫자가 나와요.

MQ2는 무엇을 재는 센서일까

이름은 '가스 센서'지만 실제로는 공기 중에 타는 성질이 있는 기체가 얼마나 있는지에 반응합니다. 연기, 알코올, 부탄 같은 것들이요.

중요한 건 어떤 기체인지는 구분하지 못한다는 점입니다. 값이 올라가도 그게 연기인지 알코올인지 알 수 없어요. 프로젝트에서 "우리 센서가 할 수 없는 일"을 설명할 때 쓰입니다.

오늘 지킬 안전 수칙

라이터 가스나 부탄을 센서에 직접 뿌리지 마세요. 값이 크게 튀면 피코 입력 한계를 넘고, 무엇보다 교실에서 위험합니다.

값을 올려보고 싶으면 입김을 불거나, 손소독제를 바른 손을 조금 떨어진 곳에서 흔들어 보세요. 그 정도면 충분히 반응합니다.

2교시활동 6. 둘을 합쳐 보기

목표 — 입력에 따라 출력이 바뀌는 구조를 만든다

오늘 배운 둘을 이어 붙입니다. 완성이 목표가 아니라 연결되는 느낌을 보는 게 목표예요. 다듬는 건 다음 시간에 합니다.

from machine import ADC, Pin
from neopixel import NeoPixel
import time

TIMING = (280, 515, 515, 745)
LED_COUNT = 10            # ★ 스틱 10, 스트립 60

gas = ADC(Pin(26))
led = NeoPixel(Pin(16), LED_COUNT, timing=TIMING)

BASE = 15000    # ★ 내 센서의 평소 값으로 바꾸세요
STEP = 1500     # ★ 한 칸 오르는 데 필요한 증가량

while True:
    value = gas.read_u16()

    n = (value - BASE) // STEP      # 몇 칸 켤지
    if n < 0:
        n = 0
    if n > LED_COUNT:
        n = LED_COUNT

    for i in range(LED_COUNT):
        if i < n:
            led[i] = (0, 60, 0)
        else:
            led[i] = (0, 0, 0)
    led.write()

    print(value, "→", n, "칸")
    time.sleep(0.3)

실행하면 십중팔구 이상할 겁니다. 평소에도 꽉 차 있거나, 입김을 불어도 하나도 안 켜지거나요. BASE와 STEP 두 숫자를 내 센서에 맞춰야 합니다.

증상고치는 법
평소에도 여러 칸 켜져 있다BASE를 올리세요
입김을 불어도 안 켜진다BASE를 내리거나 STEP을 줄이세요
살짝만 불어도 꽉 찬다STEP을 키우세요

점검하기

그로브 쉴드의 세 가지 포트는 각각 무엇을 꽂나요?
디지털(D)은 켜짐/꺼짐 신호를 쓰는 부품, 아날로그(A)는 연속적으로 변하는 값을 재는 센서, I2C는 여러 값을 한 번에 주고받는 부품을 꽂습니다.
TIMING 값을 빼면 어떻게 되나요?
기본값은 다른 부품용이라 신호를 0인지 1인지 잘못 읽습니다. 색이 깨지거나 아예 안 켜집니다.
led.write()는 왜 필요한가요?
led[0] = ...는 메모리에 적어둔 것뿐이고, write()를 불러야 실제로 LED에 신호가 전달됩니다.
MQ2 값이 처음에 계속 떨어지는 이유는?
센서 안의 히터가 달궈지는 예열 과정입니다. 고장이 아니며 몇 분 뒤 안정됩니다.
친구와 같은 코드인데 왜 LED 칸 수가 다를까요?
센서마다 평소 값이 다르기 때문입니다. BASE는 각자 자기 센서에 맞게 정해야 합니다.
